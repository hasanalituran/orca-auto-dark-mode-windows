# Agent context

This repo is an Orca plugin ("Toggle Light/Dark Theme"). It is a trusted-worker plugin
that adds a status bar button and a Theme Picker panel to switch Orca between light/dark
themes using user-selected installed themes.

## Layout

- `orca-plugin.json` — manifest (id, version, capabilities, contributions).
- `src/worker.ts` — Node worker: resolves installed themes from disk, applies them via
  `appearance.read`/`appearance.apply`, handles `toggle`, `apply`, `config.*`, `themes.list`.
- `src/panel.tsx` — components UI (Theme Picker dropdowns).
- `src/resolver.ts` — pure helpers for parsing content ids and reading theme files (tested).
- `src/resolver.test.js` — Vitest tests for resolver.
- `vitest.config.ts`, `tsconfig.json`, `tsconfig.test.json`.

## Commands

- Validate: `orca plugin validate .`
- Check/render: `orca plugin check .`
- Test: `npm test` (vitest)
- Dev load: `orca plugin dev load . --approve <fingerprint>`
- Dev reload: `orca plugin dev reload .`

## Publishing

Community plugin: public repo + `orca-plugin` topic + `vX.Y.Z` tag. No PR to
stablyai/orca-plugins. Bump `version` in orca-plugin.json for any change.

## Notes

- Do not commit `.orca/` (gitignored; generated by `orca plugin types`).
- Worker must not import local modules (Orca transpiles only the worker file); keep
  resolver logic duplicated in worker.ts and tested via resolver.ts.
- Avoid trailing "PY" in files (tooling artifact); verify with `tail`.
